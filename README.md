# Service Call Organizer Static Website

This repository contains the public marketing and policy website for Service Call Organizer (SCO).

## Included pages
- `index.html` — homepage, features, pricing, FAQ, and free-trial calls to action
- `contact.html` — support contact and trial request
- `privacy.html` — privacy policy
- `terms.html` — terms of service
- `refund-policy.html` — refund and cancellation policy
- `404.html` — not-found page
- `styles.css` and `script.js` — site styling and mobile navigation
- `assets/` — SCO logo and favicon

## GitHub Pages
For the user-site repository `bwilhite318-SCO.github.io`, publish from the `main` branch and the repository root.

## Custom domain
Do not add a `CNAME` file until DNS is configured. A safe future option is:
`sco.lsintegrations.com`

## Important review
The policy pages are practical operating drafts, not legal advice. Review them before broad commercial launch and verify that the refund, trial, renewal, and cancellation language matches the final Stripe configuration.
